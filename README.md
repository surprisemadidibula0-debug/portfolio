# RS Madidibula Portfolio

Posters and websites portfolio.

- `index.html` - the portfolio (home page)
- `business.html` - RS Madidibula Poster Design business website

## Put it online with GitHub Pages
1. On github.com, create a new repository named `portfolio` (set it to Public).
2. Click "uploading an existing file" and upload everything in this folder: `index.html`, `business.html`, `.nojekyll`, `README.md`.
3. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. After a minute your site is live at https://surprisemadidibula0-debug.github.io/portfolio/
